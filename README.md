# Hues 'n Dash

![Godot Engine](https://img.shields.io/badge/Godot-4.6-%23478cbf?logo=godot-engine&logoColor=white)
![License](https://img.shields.io/badge/License-GPLv2-blue.svg)

**Hues 'n Dash** is a vibrant, retro-inspired 2D platformer built with the Godot Engine. Navigate through color-coded challenges, harness powerful orbs, and beat the clock in this fast-paced arcade experience.

##  Game Overview

In a world defined by spectrums, you must shift your hue to survive. Pick up colored orbs to bypass matching walls, collect special power-ups to blast through enemies, and reach the goal before the 60-second timer hits zero.

### Key Features
- **Color-Shifting Mechanics:** Absorb Red, Blue, Green, and Yellow orbs to interact with the environment.
- **Timed Challenges:** 8 handcrafted levels that test your speed and precision.
- **Dynamic Power-ups:**
    - **Shoot Orb:** Fire projectiles to clear your path.
    - **Jump Orb:** Gain double-jump capabilities for vertical mobility.
- **Retro Aesthetic:** High-quality pixel art combined with a custom CRT overlay shader for that authentic arcade feel.
- **Pulse-Pounding Audio:** An original 8-bit soundtrack and crunchy retro sound effects.

##  Technical Details

- **Engine:** Godot 4.6
- **Language:** GDScript
- **Rendering:** Mobile/Desktop (Compatibility mode)
- **Features:** 
  - Custom CRT Shader Overlay
  - Global Music and UI Management
  - Scalable Level System

##  Getting Started

### Prerequisites
- [Godot Engine 4.6](https://godotengine.org/download) or newer.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/AatishAsh/project-Hues-n-Dash
   ```
2. Open Godot Engine and click **Import**.
3. Select the `project.godot` file from the cloned directory.
4. Press **F5** to run the game!

## 🕹️ Controls

| Action | Keyboard | Gamepad |
| :--- | :--- | :--- |
| **Move** | `A` / `D` or Arrows | Left Stick / D-Pad |
| **Jump** | `Space` / `W` / `Up` | A / Cross Button |
| **Shoot** | `X` / `E` | X / Square Button |
| **Pause** | `P` / `Esc` | Start Button |

you can change the input mapping in the godot settings 

## 📂 Project Structure

- `Audio/`: Sound effects and background music.
- `Documents/`: Game Design Document (GDD) and Software Requirements Specification (SRS).
- `Levels/`: The `.tscn` files for all 8 game levels.
- `Scenes/`: Modular components (Player, Enemies, Orbs, Walls).
- `Scripts/`: GDScript logic for game mechanics and UI.
- `Sprites/`: Pixel art assets and animations.
- `UI/`: Menus, HUD, and Shader overlays.
